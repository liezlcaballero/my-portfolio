PERSONAL PORTFOLIO WEBSITE

ABOUT THE PROJECT
This website serves as my personal portfolio, showcasing my academic background, 
technical skills, certificates, and projects throughout my journey as a Computer Engineering student. It also highlights my experiences and contributions to different academic and creative activities.

FEATURES

- Home: Introduction and personal profile.
- About Me: Educational background, skills, and personal information.
- Projects: Collection of academic and personal projects with descriptions and photos.
- Certificates: Compilation of certificates and achievements.
- Multimedia Works: Selected video editing projects and other creative outputs.
- Contact: Information for getting in touch.

TECHNOLOGIES USED

- HTML5
- CSS3
- JavaScript

PROJECT STRUCTURE

- index.html – Main webpage
- style.css – Website styling
- script.js – Website functionality
- images/ – Profile pictures, project photos, and certificates
- videos/ – Video project previews (if applicable)

HOW TO VIEW THE WEBSITE

1. Download or clone this repository.
2. Open the project folder.
3. Locate the index.html file.
4. Open it in your preferred web browser.

PURPOSE

The purpose of this portfolio is to present my skills, knowledge, academic accomplishments, and completed projects in one accessible platform. It also serves as a digital record of my growth and development as a future Computer Engineer.
